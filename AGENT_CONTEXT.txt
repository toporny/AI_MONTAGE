3. ARCHITEKTURA I PIPELINE — KOLEJNOŚĆ ETAPÓW
================================================================================

ETAP 1 — sync_proxies.py (OPCJONALNY, ale w batach zawsze 1.)
  - Porównuje materialy_oryginalne/ z kopie_robocze_480p/
  - Brakujące proxy: kompresuje przez FFmpeg (libx264, 854x480, 15fps, crf28)
  - Orphan proxy (bez oryginału): USUWA
  - Konwencja nazwy proxy: BASENAME.stem.lower() + "_480p15.mp4"

ETAP 2 — python main.py analyze
  - VideoAnalyzer.analyze_all_videos() skanuje kopie_robocze_480p/
  - Dla każdego .mp4 sprawdza czy jest JSON w analysis/ (cache)
  - Jeśli nie ma → analizuje (YOLO, Laplacian, OpticalFlow, SceneDetect)
  - Zapisuje analysis/<plik>.json z polami:
      file_name, duration, proxy_path, candidate_highlights[]
      (każdy highlight: start_sec, end_sec, duration, score, shot_type,
       max_people, motion_score, scene_idx)

ETAP 3 — python main.py analyze-music (lub automatycznie w create-storyboard)
  - MusicAnalyzer → beat_detector + energy_analyzer
  - Wczytuje MP3 librosa, liczy BPM, beat_times[], beat_energies[], drops[]
  - Zapisuje storyboard/music_analysis.json

ETAP 4 — python main.py create-storyboard
  Podkroki:
  a) TimelineBuilder.build_timeline_slots(music_data)
     - Iteruje beaty, wyznacza sloty o długości zależnej od energii:
       drop_or_climax: 1.2–2.2s (co 4 beaty)
       high_energy:    1.5–2.8s (co 4 beaty)
       medium_energy:  2.2–4.2s (co 8 beatów)
       calm:           3.5–6.5s (co 12 beatów)
     - Wynik: ~100 slotów dla 278s muzyki przy BPM=136

  b) MontageSelector.select_montage(slots, analyses) — GŁÓWNY ALGORYTM:
     1. Sortuje klipy chronologicznie po extract_event_timestamp(file_name)
        Wzorzec: DD_HHMMSS → dzień*86400 + godz*3600 + min*60 + sek
     2. Przypisuje file_idx (0..N-1) i event_progress (0.0..1.0)
     3. Rezerwuje ostatni slot: statyczny obraz outro (config.outro_image_path)
        lub klip "jedziemy_samochodem" (fallback)
     4. NOWE: wykrywa pliki CAPS w ORYGINALY/ (wielkie litery w nazwie)
        → metoda _find_required_caps_clips()
        → dopasowuje do analiz proxy (case-insensitive stem match)
        → rezerwuje slot proporcjonalny do file_idx
        → force-assign: score += 50.0, reason="CAPS_wymagany"
     5. Monotonic Sliding Window (etap główny, sloty 0..N-2):
        - target_idx = int(s_idx * (num_vids-1) / (num_slots-1))
        - Okna: [2, 4, 8, 15, 30, num_vids]
        - min_idx = max(last_vid_idx, target_idx - w)
        - max_idx = min(num_vids-1, target_idx + max(2, w//2))
        - Kara za odchylenie: score -= abs(file_idx - target_idx) * 0.8
        - last_vid_idx = max(last_vid_idx, chosen.file_idx) → ŚCISŁA CHRONOLOGIA

  c) StoryboardManager.export_storyboard() → storyboard.json + storyboard.txt

ETAP 5 — python main.py preview
  - PreviewRenderer.render_preview()
  - Dla każdego cut ze storyboard.json:
    * source_type == "image" → ffmpeg -loop 1 -i img -t dur -vf scale=854:480...
    * normalny klip → ffmpeg -ss start -i proxy -t dur -c:v h264_nvenc -cq 34 -p1
  - Concat list → ffmpeg concat + mix muzyki AAC 128k
  - Wynik: preview/preview_montage_480p.mp4 (~27s, ~10 MB)

ETAP 6 — python main.py render
  - FinalRenderer.render_final_master()
  - find_matching_original(proxy_name, ORYGINALY/) → case-insensitive glob
  - Dla każdego cut:
    * source_type == "image" → ffmpeg -loop 1 -vf scale=3840:2160... hevc_nvenc
    * normalny klip → ffmpeg -ss -i orig -t -c:v hevc_nvenc -cq 19 -preset p6
  - Concat + muzyka AAC 320k → output/final_montage_4K60.mp4
  - Czas ~7-10 min na RTX 3090

--- utils/helpers.py ---
Kluczowe funkcje:
  extract_event_timestamp(filename) → float
    Parsuje DD_HHMMSS z nazwy pliku → sekundy absolutne
    Używane do chronologicznego sortowania klipów
    Fallback: st_mtime lub 0.0

  find_matching_original(proxy_path, originals_dir) → Optional[Path]
    Case-insensitive lookup: sprawdza stem.lower(), stem.upper(), stem.capitalize()
    Potem iterdir() case-insensitive glob po wszystkich plikach wideo
    Wspiera rozszerzenia: .mp4 .mov .mkv .avi .mts .m2ts
    WAŻNE: obsługuje pliki CAPS w ORYGINALY/

  get_base_stem(filename) → str
    Usuwa sufiks _480p15, _proxy, _low z nazwy (regex re.IGNORECASE)

  run_command(cmd) → CompletedProcess
    Wrapper subprocess z logowaniem

--- montage/selector.py ---
NAJWAŻNIEJSZY PLIK. Dwie klasy/funkcje:

  _has_uppercase(filename) → bool   (helper globalny)
    re.search(r"[A-Z]", stem)

  MontageSelector._find_required_caps_clips(sorted_videos) → List[Dict]
    1. Skanuje original_dir, zbiera stems plików z CAPS → Set[str] (lowercase)
    2. Dla każdego video w sorted_videos: dopasowuje stem (bez _480p15) do caps_stems
    3. Zwraca listę analiz które MUSZĄ być w montażu

  MontageSelector.select_montage(slots, analyses) → List[Dict]
    Wynik: lista cut_entry (patrz storyboard.json format poniżej)
    Kluczowe pola cut_entry: cut_idx, timeline_start/end, duration,
      source_file (proxy name), proxy_path, source_start, source_end,
      source_clip_duration, score, highlight_base_score, shot_type,
      max_people, motion_score, event_time, event_progress, reason,
      music_energy, is_drop
    Specjalne: source_type="image", image_path (dla outro z obrazka)

6. ALGORYTMY KLUCZOWE
================================================================================

[A] CHRONOLOGICZNE SORTOWANIE KLIPÓW
  extract_event_timestamp("29_130535_...") → 29*86400 + 13*3600 + 05*60 + 35 = 2556335
  Pliki posortowane → file_idx 0..N-1 → event_progress 0.0..1.0
  target_idx dla slotu s: int(s_idx * (N-1) / (S-1))
  Wynik: klipy z rana → początki montażu, wieczorne → końcówka

[B] MONOTONIC SLIDING WINDOW
  last_vid_idx = 0 (rośnie, nigdy nie cofa)
  Dla s_idx=0: szukaj w oknie [max(0, target-2) .. min(N, target+1)]
  Jeśli nie znaleziono → rozszerz okno: 2→4→8→15→30→all
  Penalty: score -= abs(file_idx - target_idx) * 0.8
  Po wyborze: last_vid_idx = max(last_vid_idx, chosen.file_idx)
  EFEKT: zero skoków wstecz w chronologii

[C] GWARANCJA KLIPÓW CAPS
  Skanuj ORYGINALY/ → stem.lower() do set jeśli re.search(r"[A-Z]", stem)
  Dopasuj do analiz: proxy_stem = re.sub(r"_480p\d*$", "", stem, IGNORECASE).lower()
  Dla każdego CAPS-klipu: target_slot = file_idx * (S-1) / (N-1)
  Zajmij slot (z dryf-odsuniéciem jeśli kolizja), force-assign highlight
  score += 50.0, reason="CAPS_wymagany"

[D] SCORING DOPASOWANIA (MontageScorer.calculate_match_score)
  base_score = highlight.score (wynik analizy wideo)
  + energy_bonus (drop+motion → +20, top_highlight → +35)
  + shot_type bonus (medium shot na dropa → +10)
  - recent_history penalty (ostatnie 4 ujęcia: shot_type == current → -30)
  - clip_reuse penalty (ten sam plik użyty wcześniej → -60)
  - idx_diff penalty (odchylenie od target_idx → -0.8 per indeks)
  Zwraca (total_score, reason_string)

[E] STATYCZNY OBRAZ OUTRO
  Jeśli config.outro_image_path i plik istnieje:
    FFmpeg: -loop 1 -i img.jpg -t SLOT_DUR -vf scale=W:H:force_original_aspect_ratio=decrease,pad=...
    Zapisywane w storyboard.json jako: source_type="image", image_path=...
  Sprawdzane w KAŻDYM renderer (preview i final) przez:
    if cut.get("source_type") == "image": ...
